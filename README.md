# 연구 아이디어 → 연구계획서 에이전트

교육공학·학습과학·AI융합교육 분야의 연구 아이디어를 실행 가능한 석사학위 연구계획서로 구체화하기 위한 Codex 프로젝트 지침과 보조 도구입니다. 이 저장소는 독립 실행 프로그램이 아니라 `AGENTS.md`의 연구 절차를 Codex가 따르도록 구성되어 있습니다.

## 사용법

1. Codex에서 이 저장소 폴더를 프로젝트로 엽니다.
2. 새 작업에 연구하고 싶은 교육적 문제를 한두 문장으로 적습니다. 대상·수업 맥락, 연구 기간, 접근 가능한 자료도 알고 있는 범위에서 함께 알려주세요.
3. Codex가 필요한 핵심 사항을 질문한 뒤 잠정 설계를 제안합니다. 대상, 연구문제, 자료 접근과 방법을 정하고 나면 전체 연구계획서와 재생성 파일을 작성할 수 있습니다.
4. 문헌 에이전트는 계획서 초안을 받은 뒤 별도 승인을 얻어 실행합니다. 승인 전에는 문헌 수집이나 PDF 저장을 시작하지 않습니다.

모델 지정, 문헌 검증, 연구윤리, 출력 파일과 검증 절차는 루트의 [`AGENTS.md`](AGENTS.md)에 적혀 있습니다. 연구 아이디어와 접근 가능한 자료를 제공하면 해당 절차에 따라 작업을 시작할 수 있습니다.

## 구성

- `AGENTS.md`: 연구 질문, 설계, 문헌 검토, 윤리, 계획서 작성 절차
- `문헌수집_에이전트/AGENTS.md`: 승인된 연구계획서에 대한 문헌 수집 지침
- `파싱_에이전트/`: 승인된 PDF를 로컬에서 파싱하는 Node.js 도구와 사용법

PDF 파서 설치, 실행, 승인 절차는 [`파싱_에이전트/README.md`](파싱_에이전트/README.md)를 참고하세요. 파서는 Node.js 20 이상과 pnpm이 필요합니다.
