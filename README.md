# 연구 아이디어 → 연구계획서 에이전트

교육공학·학습과학·AI융합교육 분야의 연구 아이디어를 실행 가능한 연구계획서로 구체화하기 위한 운영 지침과 보조 도구입니다.

## 구성

- `AGENTS.md`: 연구 질문, 설계, 문헌 검토, 윤리, 계획서 작성 절차
- `문헌수집_에이전트/AGENTS.md`: 승인된 연구계획서에 대한 문헌 수집 지침
- `파싱_에이전트/`: 승인된 PDF를 로컬에서 파싱하는 Node.js 도구와 사용법

파서 설치와 사용 방법은 [`파싱_에이전트/README.md`](파싱_에이전트/README.md)를 참고하세요.
