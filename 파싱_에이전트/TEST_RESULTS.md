# 제작 검증 결과

검증일: 2026-10-11 (한국 시간)

## 환경 및 실제 실행

- Windows, Node.js v24.19.0, pnpm 11.25.0.
- kordoc 4.21.22, csv-parse 6.1.0. 프로젝트 로컬 설치 및 `pnpm install --frozen-lockfile` 최종 종료 코드 0.
- 로컬 PP-OCRv5 모델을 `.cache/models`에 준비한 후 오프라인 파싱 확인.
- `node --test tests/parser.test.mjs`: **12개 통과, 0개 실패**.
- 실제 논문 AD01·AD06은 CSV 및 파일 존재 미리보기만 수행. PDF 본문·해시를 읽거나 변환하지 않았으며 실제 문헌수집 폴더에 파싱 결과 폴더가 생성되지 않았음을 확인.
- Luna / High 실행 규칙은 지침에 작성했으며 이번 제작 과정에서는 실제 문헌 파싱 담당자를 생성하지 않음. 모델 지정 성공을 시험한 것으로 보고하지 않음.

## 시험 범위

| 시험 | 방식 | 결과 |
| --- | --- | --- |
| 승인 근거·ID 누락 | 인수 검사 | 실제 실행 거부 |
| BOM·쉼표·따옴표·한글 CSV | 실제 CSV 파서 | 정상 인식 |
| 잘못된 ID·중복 ID·필수 열 누락 | 입력 시험 | 파싱 전 거부 |
| dry-run | 파서 호출 금지 및 출력 부재 검사 | 통과 |
| 빈 본문·대체 문자·페이지 누락·표·OCR 경고 | 합성 파서 결과 | 검토 필요 판정 |
| 동일 결과 재사용 | 모의 파서 호출 수 검사 | 완료 결과 재사용 |
| 수작업 Markdown 변경 | 모의 파서 및 파일 내용 검사 | 기존 수정 보존, 새 버전 생성 |
| 원본 PDF 해시 변경 | 합성 파일 및 모의 파서 | 기존 결과 보존, 새 버전 생성 |
| 검토 필요 재시도 | 모의 파서 | 완료 캐시로 오인하지 않음 |
| 실패 격리·미확보 제외 | 모의 파서 및 실제 경로 검사 | 나머지 파일 계속 처리 |
| 한글 텍스트·한글 경로·2쪽 PDF | 실제 kordoc | 본문 및 두 페이지 추출 |
| 손상 PDF | 실제 kordoc | 실패 판정 |
| 로그인 HTML·누락 파일 | 실행 코드 | PDF로 처리하지 않음 |
| 스캔 PDF, 모델 없음 | 실제 kordoc 오프라인 | OCR_FAILED·NEEDS_OCR 경고, 검토 필요 |
| 스캔 PDF, 모델 준비 후 | 실제 kordoc 오프라인 | 두 문장 정상 OCR, OCR_APPLIED 표시 및 검토 필요 |

모의 시험과 실제 kordoc 시험은 위 표에서 구분했다. 모델 누락 시험은 최초 설치 직후 수행했고, 모델 준비 후 추가로 재검증했다. 최종 12개 자동 테스트는 일부 행을 묶어서 검사한다.

## 시각 및 텍스트 대조

- 합성 정상 PDF 2쪽과 스캔 PDF 1쪽을 Poppler로 렌더링하고 총 3쪽 이미지를 확인했다. 본문 잘림·겹침·한글 표시 이상이 없었다.
- 정상 PDF의 제목, 한글 본문, 영문 문장과 2쪽 문장을 Markdown과 대조했다.
- 스캔 PDF의 “스캔 문서 파싱 시험”, “학습자는 피드백을 읽습니다.”가 최종 오프라인 결과에 모두 존재함을 확인했다.
- Poppler 실행 중 일부 언어 nameToUnicode 리소스 경로 경고가 발생했지만 PNG 생성에 성공했고 한국어 화면을 직접 확인했다.

## 한계

- 실제 학술 논문, 복잡한 병합 표·다단·수식·각주에 대한 정확도 검증은 수행하지 않았다. 실제 논문 파싱은 사용자 별도 승인 후 진행한다.
- 자동 점검은 의미상 오인식이나 읽기 순서 정확성을 보증하지 않는다. 실제 문헌은 AGENTS.md의 시각 검토 절차를 적용한다.
- 이미지 바이너리와 수식 전용 OCR은 기본 저장·처리 범위에서 제외한다. kordoc이 남기는 그림 위치 표지는 원본 PDF를 참고해야 한다.
- 프로세스 시간 제한은 구현했으며 실제 180초 경과 대기 시험은 수행하지 않았다.
- 이번 설치의 첫 시도는 네트워크 제한 및 pnpm 빌드 설정 때문에 완료되지 않았다. 프로젝트 설정과 설치 실행 권한을 해결한 최종 고정 버전 설치는 성공했다.
